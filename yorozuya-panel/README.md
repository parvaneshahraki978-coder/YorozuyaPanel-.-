# YorozuyaPanel 🍓 — نسخه ۱.۰.۰

پنل سبک مدیریت کانفیگ و لینک اشتراک پروکسی، با تم گینتاما و رابط کاربری کاملاً فارسی (RTL).
بک‌اند با **FastAPI**، فرانت با **HTML/CSS/JS خام**، و ذخیره‌سازی با **فایل JSON** (بدون دیتابیس).

---

## ✨ امکانات

- **کاربران:** ساخت، ویرایش، فعال/غیرفعال، حذف، ریست ترافیک، تعویض لینک اشتراک، جست‌وجو و فیلتر بر اساس وضعیت.
- **انقضا و حجم:** تاریخ انقضا (با نمایش شمسی) و سقف ترافیک بر حسب گیگ. کاربر منقضی خودکار غیرفعال می‌شه؛ اما هیچ‌وقت حذف نمی‌شه.
- **نودها:** VLESS، VMess، Trojan و Shadowsocks، با انتقال TCP / WebSocket / gRPC و امنیت none / TLS / REALITY.
- **چک نود:** resolve دامنه و اتصال TCP با تایم‌اوت ۵ ثانیه (تأخیر = زمان اتصال). تکی یا گروهی، همراه با نمایش کشور نود.
- **لینک اشتراک:** خروجی base64 استاندارد، خروجی متنی، هدر `Subscription-Userinfo` (حجم و انقضا)، QR کد PNG و صفحه‌ی عمومی `/p/{key}`.
- **ایمپورت مستقیم در اپ:** V2RayNG، NekoBox، Streisand، V2Box، Hiddify و Happ.
- **ابزارها:** آی‌پی و کشور سرور، و جست‌وجوی آی‌پی یا دامنه.
- **بکاپ:** دانلود فایل JSON کامل و ریستور از همان فایل.
- **ظاهر:** فونت فارسی، تاریخ شمسی، جمله‌های طنز اصلی، و لوگوی اختصاصی با تابلوی چوبی «万事屋» در تم گینتاما.

> ℹ️ **ترافیک:** در نسخه‌ی ۱.۰.۰ مصرف ترافیک به‌صورت زنده اندازه‌گیری نمی‌شه. حجم مصرفی را خودت وارد یا ریست می‌کنی. اندازه‌گیری زنده از Xray در نقشه‌ی راه است.

## 🚀 اجرای لوکال

```bash
cd yorozuya-panel
python -m venv .venv
source .venv/bin/activate            # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
ADMIN_PASSWORD="رمز-قوی-تو" PORT=8080 python main.py
```

بعد از اجرا، آدرس `http://localhost:8080` را باز کن.
اگه `ADMIN_PASSWORD` ست نشده باشه، رمز پیش‌فرض `yorozuya` فعاله؛ فقط برای تست لوکال.

## ☁️ دیپلوی روی Render (حالت زیرپوشه)

این پروژه داخل زیرپوشه‌ی `yorozuya-panel/` ریپو قرار داره. **از دکمه‌ی Blueprint استفاده نکن.** دیپلوی را دستی انجام بده:

1. در Render: **New → Web Service** و ریپو `parvaneshahraki978-coder/YorozuyaPanel-.-` را وصل کن.
2. **Branch:** برنچی که می‌خوای دیپلوی بشه (مثلاً `arena/8c67ee6a-yorozuyapanel`، یا `main` بعد از merge).
3. **Root Directory:** `yorozuya-panel` ← مهم‌ترین تنظیم همین‌جاست.
4. **Runtime:** Docker (Render فایل `Dockerfile` داخل Root Directory را پیدا می‌کنه).
5. **Instance Type:** Free.
6. **Health Check Path:** `/healthz`
7. **Environment Variables:** `ADMIN_PASSWORD` (رمز قوی) و `SECRET_KEY` (یک رشته‌ی تصادفی طولانی).
8. **Create Web Service** را بزن و صبر کن Build و Deploy تموم بشه. بعد آدرس `*.onrender.com` را باز کن.

فایل `render.yaml` فقط مرجع تنظیمات است. اگه بعداً پروژه را به ریشه‌ی ریپو منتقل کنی، می‌شه همان فایل را مستقیم Blueprint کرد.

> ⚠️ **نکته‌ی مهم درباره‌ی پلن رایگان:** پلن Free دیسک پایدار ندارد. یعنی با هر دیپلوی یا ری‌استارت، فایل داده (کاربران و نودها) پاک می‌شه.
> قبل از هر دیپلوی **بکاپ JSON بگیر** و بعد از دیپلوی، از بخش **تنظیمات ← ریستور** برش گردون.
> سرویس رایگان هم بعد از مدتی بی‌فعالیتی می‌خوابه و اولین درخواست کندتر جواب می‌ده.
> اگه دیسک می‌خوای، پلن را ارتقا بده و در تنظیمات سرویس بخش **Disks** را با Mount Path برابر `/app/data` اضافه کن (نمونه‌اش در `render.yaml` کامنت شده).

## 🔗 اشتراک و لینک‌ها

- `GET /api/sub/{key}` خروجی **base64** می‌ده. با `?format=text` لینک‌ها به‌صورت خام برمی‌گردن.
- هدرهای پاسخ: `Subscription-Userinfo` (مصرف، سقف و انقضا)، `Profile-Title` (base64) و `Profile-Update-Interval: 12`.
- اشتراک فقط برای کاربر **فعال** جواب می‌ده. برای کاربر غیرفعال، منقضی یا با حجم تموم‌شده، پاسخ `403` با پیام فارسی برمی‌گرده.
- لینک هر نود:
  - `vless://` و `trojan://` با UUID کاربر ساخته می‌شن. REALITY فقط برای VLESS و Trojan مجازه.
  - `vmess://` به‌صورت JSON با base64 ساخته می‌شه.
  - `ss://` به‌صورت `base64(method:password)@host:port` ساخته می‌شه.
- ریمارک همه‌ی لینک‌ها به شکل `🍓 نام‌نود` است و URL-encoded می‌شه.

## 📜 قوانین کار

- **تاریخ انقضا:** فرمت `YYYY-MM-DD` یعنی پایان همان روز، ساعت ۲۳:۵۹:۵۹ به وقت UTC. در رابط کاربری، تاریخ به وقت مرورگر حساب می‌شه. ساختن کاربرِ فعال با تاریخ گذشته، یا فعال‌کردن کاربرِ منقضی، خطای `400` می‌ده.
- **Sweeper:** هر ۳۰ ثانیه کاربرهای منقضی غیرفعال می‌شن (با علامت `auto_disabled`) ولی حذف نمی‌شن. وقتی تاریخ یک کاربر منقضی تمدید بشه، در فرم ویرایش تیک «فعال» خودکار زده می‌شه.
- **وضعیت کاربر:** اولویت با این ترتیبه: منقضی، سپس غیرفعال، سپس حجم تمام، و در آخر فعال.
- **چک نود:** resolve دامنه و اتصال TCP با تایم‌اوت ۵ ثانیه. کشور نود از ip-api گرفته و ۷ روز کش می‌شه. اگه موقعیت‌یابی جواب نده، نتیجه‌ی چک نود همچنان ثبت می‌شه.
- **آی‌پی سرور:** از ip-api.com گرفته و ۱۰ دقیقه کش می‌شه. اگه ip-api جواب نده، آی‌پی خروجی از api.ipify.org گرفته می‌شه.
- **ذخیره‌سازی:** فایل `DATA_DIR/yorozuya_state.json` با نوشتن اتمیک. ذخیره‌ی خودکار هر ۳۰ ثانیه و هنگام خاموش شدن انجام می‌شه. اگه فایل خراب باشه، به `yorozuya_state.broken-*.json` تغییر نام می‌ده و سرور با داده‌ی خالی بالا می‌آد.

## 🔐 امنیت

- برای `ADMIN_PASSWORD` رمز قوی بذار. مقدار `yorozuya` فقط برای تست لوکال مناسبه.
- کوکی نشست `yorozuya_session` است: HttpOnly، SameSite=Lax و اعتبار ۱۲ ساعت. پشت HTTPS، Secure هم می‌شه.
- محدودیت ورود: بعد از ۱۰ تلاش ناموفق در ۵ دقیقه برای هر IP، درخواست‌های بعدی با `429` رد می‌شن.
- لینک اشتراک مثل کلید دسترسیه. اگه لو رفت، از دکمه‌ی **تعویض لینک** استفاده کن.
- فایل بکاپ شامل UUID و کلید اشتراک کاربرهاست. مثل رمز نگهش دار و هرگز داخل Git نذار.

## 💾 بکاپ و ریستور

- `GET /api/backup` (یا دکمه‌ی «دانلود بکاپ JSON» در تنظیمات): فایل JSON شامل کاربران، نودها، تنظیمات و کش موقعیت.
- `POST /api/restore` (یا فرم ریستور در تنظیمات): فایل را می‌گیرد و کل داده‌ی فعلی را با محتوای آن جایگزین می‌کنه. حداکثر حجم فایل ۲۰ مگابایته.
